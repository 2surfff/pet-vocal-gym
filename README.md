# Vocal Gym — локальний аудіо-тренажер для вокалістів і музикантів (MVP)

Локальний веб-застосунок для тренування чистоти інтонування, слуху та інтервалів у реальному часі. Працює на FastAPI + SQLite (бекенд) та чистому фронтенді (HTML5 Canvas, ES6 Modules, Web Audio API, Tone.js).

## Структура проєкту

```text
vocal-gym/
├── backend/
│   ├── __init__.py
│   ├── main.py              # FastAPI застосунок, роздача статики та API-роути
│   ├── database.py          # Асинхронне підключення до SQLite (aiosqlite) та таблиці
│   ├── schemas.py           # Pydantic-моделі для вправ (JSON) і результатів
│   └── seed_data.py         # 3 стартові вправи (гама C3-G3, розспівка A3-A4, стрибки на квінту)
├── frontend/
│   ├── index.html           # Головний екран: вибір вправи, Canvas, індикатор ноти, кнопки
│   ├── styles.css           # Мінімалістичний темний UI в стилі музичної студії
│   └── js/
│       ├── app.js           # Головний контролер стану (старт/стоп вправи, відправка звіту)
│       ├── pitch_detector.js # Алгоритм визначення частоти (Гц -> нота + центи)
│       ├── synth.js         # Обгортка над Tone.js для програвання JSON-вправ і метронома
│       └── visualizer.js    # Рендеринг нотної доріжки та кривої голосу на HTML5 Canvas
├── requirements.txt         # fastapi, uvicorn, pydantic, aiosqlite
└── README.md                # Інструкція запуску
```

## Швидкий старт

1. Створіть та активуйте віртуальне середовище Python:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустіть сервер FastAPI:
   ```bash
   uvicorn backend.main:app --reload --port 8000
   ```

4. Відкрийте у браузері:
   ```text
   http://localhost:8000
   ```

## Як користуватися

1. Натисніть **«Увімкнути мікрофон»** і надайте браузеру доступ до мікрофона (для перевірки без мікрофона доступний режим **«Демо-симуляція»**).
2. Оберіть одну зі стартових вправ у бічній або верхній панелі.
3. Натисніть **«Старт вправи»** — пролунає 1 такт відліку метронома (4 удари), після чого електропіаніно зіграє мелодію, а на Canvas рухатимуться блоки нот.
4. Співайте синхронно з блоками. Колір лінії голосу показує точність інтонування:
   - **Зелений**: відхилення до 15 центів
   - **Жовтий**: відхилення від 15 до 35 центів
   - **Червоний**: відхилення понад 35 центів
5. Після завершення вправи збережеться статистика (XP, щоденний стрік та точність по кожній ноті для визначення проблемних нот).
